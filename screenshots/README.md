# Screenshots & Evidence

Screenshots will be added here as the lab is exercised and documented.

## Before Publishing

Redact or remove:

- Real IP addresses when disclosure is inappropriate
- Usernames and email addresses
- Passwords and API keys
- Tailscale identifiers or auth material
- Internal hostnames
- Personal files or private data
- Tokens and session information

Preferred evidence includes Wazuh alerts, Splunk searches/results, timelines, Suricata events, DNS telemetry, and sanitized architecture views.

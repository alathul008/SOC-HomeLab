# Investigations

This directory will contain sanitized case studies from the home lab.

## Case Format

```text
Case ID
├── Summary
├── Detection
├── Timeline
├── Affected Host / Account
├── Evidence
├── IOCs
├── MITRE ATT&CK
├── Severity
├── Analysis
├── Containment
├── Remediation
└── Lessons Learned
```
